# AI-Financial-Insight

## What is AI-Financial-Insight?

- 一个从 0 到 1 的「财经情绪分析」全栈小项目。(练习学习向)

## goal

本项目的目标是通过关键词分析情绪统计结果，并返回对应情绪分布饼图。

## MVP(Phase 1)

### 1）backend(flask)

- 情绪分析API

  接口内部做什么？

  1. 接受前端输入的关键词参数
  2. 获取与关键词相关的若干文本数据（当前为简化数据源）
  3. 对文本进行情绪分析（正面 / 负面）
  4. 统计正负面数量
  5. 以 JSON 格式返回分析结果
  
  > 请求方式：GET
  >
  > 接口路径：/api/analyse
  >
  > 请求参数：
  >
  > - keyword：财经关键词
  >
  > 返回实例：
  >
  > ```json
  > {
  >     "keyword":"新能源",
  >     "positive":6,
  >     "negative":4
  > }
  > ```

### 2）AI情感分析

1. 基于规则的简单情绪判断
2. 使用 TextBlob 进行情感分析
3. 使用 HuggingFace 预训练情感分析模型（可选）

### 3）数据来源

- 当前版本使用简化数据源，重点验证系统流程

- 后续可扩展为实时财经新闻或评论爬取

###4）Frontend（vue)

- 提供关键词输入表单
- 调用后端情绪分析接口
- 使用 ECharts 将分析结果以饼图形式展示
