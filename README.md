# AI-Financial-Insight
# 🧭 AI理财助手项目计划书（含金融学习路径）

## 一、项目概述

| 项目名称 | AI 理财助手（AI Financial Insight） |
|-----------|------------------------------------|
| 周期 | 3个月（2025.10.18 - 2026.1.20） |
| 开发目标 | 构建一个能分析财经情绪、展示行情趋势的网页应用 |
| 技术路线 | 前端：Vue + ECharts ｜ 后端：Flask（Python） ｜ 数据：爬虫 + AI分析 |
| 学习方向 | AI + 金融（零基础起步） |
| 最终成果 | 可展示的在线Demo + GitHub完整仓库 + 报告与展示PPT |

---

## 二、核心目标

1. 熟悉前后端协作开发流程（Vue + Flask）
2. 初步掌握AI文本分析（财经新闻情感分析）
3. 理解基础金融概念（股票、指数、市场情绪）
4. 实现完整项目部署（Vercel + Render）
5. 输出展示文档与个人报告

---

## 三、系统功能设计

| 模块 | 功能描述 | 技术要点 |
|------|-----------|----------|
| 数据获取 | 爬取新浪财经/雪球等财经网站数据 | requests + BeautifulSoup |
| AI分析 | 对财经评论进行情感分类（正面/负面） | TextBlob / Transformers |
| 后端API | 提供REST接口供前端调用 | Flask / Flask-RESTful |
| 前端展示 | 可视化显示情绪结果和行情 | Vue3 + ECharts |
| 搜索功能 | 用户输入关键词查看分析结果 | Axios + Vue表单 |
| 部署与协作 | GitHub仓库管理与在线部署 | Git / Vercel / Render |
