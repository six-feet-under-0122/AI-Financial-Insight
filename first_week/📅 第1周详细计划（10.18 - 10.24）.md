### 🧱 技术部分：前后端初步运行 ###

 **步骤：**

   ```bash

   cd frontend
   npm install
   npm run dev
   ```

   在浏览器中打开 `http://localhost:5173`

2. **后端：**

   ```bash
   pip install flask
   touch backend/app.py
   ```

   **app.py：**

   ```python
   from flask import Flask
   app = Flask(__name__)
   
   @app.route('/')
   def home():
       return "Hello from Flask!"
   
   if __name__ == '__main__':
       app.run(debug=True)
   ```

   打开 `http://127.0.0.1:5000` 查看结果。
